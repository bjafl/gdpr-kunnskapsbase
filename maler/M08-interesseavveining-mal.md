# M08 – Interesseavveining (art. 6 nr. 1 bokstav f) – trestegstest

*Bruk: Én utfylt mal per behandlingsaktivitet og formål. Har behandlingen flere aktiviteter eller formål (f.eks. både motivasjon for brukeren og oppfølging fra veileder), lag separate vurderinger [K02 s. 10]. Malen bygger på Datatilsynets tre vilkår og spørsmålsliste [K02 s. 9–10]. Bakgrunn: [T02](../temaer/T02-behandlingsgrunnlag-og-samtykke.md); arbeidsflyt: [A06](../arbeidsflyter/A06-vurdere-behandlingsgrunnlag.md). Lovtekst: [art. 6 nr. 1 f](../kilder/K43-gdpr-kap02-prinsipper.md#art-6), [art. 21](../kilder/K43-gdpr-kap03-den-registrertes-rettigheter.md#art-21).*

*Alle tre vilkår må være oppfylt. Konklusjonen skal dokumenteres for å kunne vise etterlevelse [K02 s. 9], og informasjon om avveiningen bør kunne gis den registrerte på forespørsel [K06 s. 2; K26 vedlegg].*

**[Merknad – ikke fra kildene]** EDPB Guidelines 1/2024 om berettigede interesser (nevnt i [K02 s. 10]) gir en tilsvarende trinnvis metode og flere eksempler; sjekk endelig versjon ved behov.

## Steg 3 – Avveining: går interessen foran den registrertes interesser, rettigheter og friheter?

### 3a. Virksomhetens side

|---|---|

| Kan behandlingen ha **positive konsekvenser** for de registrerte? [K02 s. 10] | |

### 3b. Den registrertes side

| Spørsmål [K02 s. 9–10] | Svar / vekt |

| Hvilken type opplysninger? Hvor sensitive? | |
| Kan behandlingen oppleves krenkende? Mener de registrerte selv at den er krenkende? | |

| Kan den skape en **nedkjølende effekt**? | |
| Hvilke **rimelige forventninger** har (eller bør) de registrerte ha, ut fra forholdet til virksomheten og konteksten? | |
| Hvor mange personer berøres? | |
| Vil ulempene vare over tid? | |
| Kobles ulike typer personopplysninger sammen (profilering)? | |
| Gjelder det **mindreårige** eller andre sårbare? | |

### 3d. Samlet avveining

*Beskriv hvorfor interessen veier tyngre (eller ikke), med henvisning til punktene over. Jo mer detaljert og inngripende behandlingen er, desto mer skal til [K02 s. 10]. Inngripende sporing og profilering for markedsføring er vanskelig å begrunne med berettiget interesse [K39 s. 28–29].*
